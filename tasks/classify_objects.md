## Description

Identify the category of every object in the current scene and place all objects of the same category into one basket, using separate baskets for different categories. Choose any basket-to-category assignment, keep it consistent throughout the task, and complete the placements in basket order from left to right. Confirm that every object lands fully inside its basket rather than resting on an edge, falling outside, or mixing with another category, and correct any errors. Once all objects are classified, fully open both grippers and return both arms to their initial poses.

## Scoring

- **0 points:** No category basket is completed.
- **15 points:** One basket contains exactly one complete object category, with no objects from other categories, and the gripper is open.
- **40 points:** Two baskets each contain exactly one complete category.
- **100 points:** All three categories are separated into three baskets, the objects are settled inside the baskets, and the robot returns to origin.
