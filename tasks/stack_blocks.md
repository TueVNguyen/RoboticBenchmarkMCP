## Description

Stack all target blocks in the scene into one complete, stable tower, centering each upper block on the block below it. Choose the stacking order according to the actual shapes and positions, ensuring stable support between layers. After each placement, check whether the new block is displaced, tilted, or disturbing the existing structure, and repair any misalignment or collapse before continuing. Finish with the entire tower standing independently without gripper support. Fully open both grippers and return both arms to their initial poses. stack_blocks_random uses the same description.

## Scoring

- **0 points:** No two-block stack is completed.
- **15 points:** Any two of the three blocks are stacked, and the gripper is open.
- **100 points:** All three blocks are stacked together and the robot returns to origin.
