## Description

Read the current language instruction to determine the required bottom-to-top color order, then stack all specified blocks into one tower in that order. Keep the bottom block supported by the table and center each upper block on the one below. Check the color sequence and structural stability as each layer is completed, correcting any wrong order, displacement, or collapse before continuing. Confirm that the tower remains stable and matches the instruction after release. Fully open both grippers and return both arms to their initial poses.

## Scoring

- **0 points:** The first ordered stack is not completed.
- **20 points:** The first two specified blocks are stacked in the instructed order, the bottom block remains on the table, and the gripper is open.
- **100 points:** All three specified blocks are stacked in order and the robot returns to origin.
