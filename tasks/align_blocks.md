## Description

Use the set square to push all target blocks on the table into a straight row with consistent orientation. Keep every block supported by the tabletop throughout the task and do not pick up the blocks. Check whether the row is straight and whether any individual block is rotated or protruding, and correct the remaining differences. Once all blocks are stably aligned, fully open both grippers and return both arms to their initial poses.

## Scoring

- **0 points:** The alignment, reset, or no-lift condition is not satisfied.
- **100 points:** The three cubes are in one straight aligned row, the robot returns to origin, and no cube has been lifted above the allowed height during the episode.
