## Description

Read the current language instruction to determine which object category belongs in the left, middle, and right baskets, then place every object into its assigned basket. Follow the instruction rather than assuming a category assignment from basket colors. Check that each object is fully inside the correct basket and correct any mixing, omission, or object resting on a rim. Fully open both grippers and return both arms to their initial poses.

## Scoring

- **0 points:** No specified category is placed into its assigned basket.
- **10 points:** One specified category is placed into its assigned basket, no other objects are in that basket, and the gripper is open.
- **40 points:** Two specified categories are placed into their assigned baskets, with no extra objects in those baskets.
- **100 points:** All three specified categories are placed into the left, middle, and right baskets as instructed, no basket contains objects from another category, and the robot returns to origin.
