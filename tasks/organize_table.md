## Description

Place the alarm clock upright on top of the cabinet, the figurine upright at the center of the gray square base beside the cabinet, the mouse on its mouse pad, and the keyboard flat and centered over its marked frame so that it covers the marked area. Orient both the mouse and the keyboard toward the computer screen. Complete the placements in any order while checking each object's position, orientation, and stability. Fully open both grippers and return both arms to their initial poses.

## Scoring

- **0 points:** No target item is organized correctly.
- **25 points:** Any one target item is organized correctly: mouse on mouse pad, keyboard in the frame, figurine on its stand, or alarm clock on the drawer, with the gripper open.
- **50 points:** Any two target items are organized correctly.
- **75 points:** Any three target items are organized correctly.
- **100 points:** All four target items are organized correctly and the robot returns to origin.
